# Lab Architecture

## Overview
This lab simulates a SOC monitoring environment using Wazuh in a virtual environment

---

## Components

- Wazuh Server (Ubuntu)
- Windows 11 Endpoint (Sysmon + Wazuh Agent)
- Ubuntu Endpoint (Wazuh Agent)
- Kali Linux (Attacker)

---

## Network Layout

All machines are connected within a virtual network using a virtual machine for attack simulation, threat detection and monitoring.
