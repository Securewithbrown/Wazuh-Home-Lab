# Professional Summary

Designed and implemented a Wazuh-based Security Information and Event Management (SIEM) home lab to simulate real-world Security Operations Center (SOC) monitoring and incident response workflows. The environment consisted of a centralized Wazuh server, Windows and Linux endpoints, Sysmon integration, and a dedicated attack simulation system.

The project involved deploying and configuring Wazuh agents, integrating Sysmon for enhanced endpoint visibility, implementing File Integrity Monitoring (FIM), and conducting security testing through SSH brute-force attack simulations. Security events were successfully detected, analyzed, and investigated using Wazuh dashboards, alerts, and log telemetry. Active Response functionality was also configured to automatically block malicious IP addresses following repeated authentication failures.

This project provided practical experience in SIEM deployment, security monitoring, threat detection, incident investigation, endpoint security, Linux administration, and cybersecurity documentation. It also strengthened skills in security operations, log analysis, attack detection, and automated incident response.
